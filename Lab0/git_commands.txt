1) git clone - копирует удалённый репозиторий на комп
2) git status - показывает текущее состояние папки: что изменено, что добавлено и тд
3) git add - сохраняет изменения для следующего коммита
4) git commit - сохраняет добавленные изменения в локальную историю
5) git push - отправляет локальные коммиты на удалённый сервер чтобы поделиться своей работой с другими
6) git pull - забирает изменения с удалённого репозитория и сразу применяет их к своему коду
7) git branch - показывает список веток или создать новую
8) git checkout - переключиться на другую ветку или откатить файл к предыдущему состоянию
9) git merge - слить изменения из одной ветки в другую
10) git log - показать историю всех коммитов - где, кто, когда, что и у кого
11) git init - создать новый пустой репозиторий в текущей папке
12) git diff — показать конкретные отличия между файлами
